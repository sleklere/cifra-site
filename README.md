# Cifra

Página pública de presentación de Cifra, una aplicación de finanzas personales centrada en el registro y análisis de gastos.

Sitio: https://sleklere.github.io/cifra-site/

## Desarrollo

El sitio usa HTML y CSS estáticos, sin dependencias ni proceso de compilación.

Para verlo localmente, ejecutar desde esta carpeta:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Abrir http://127.0.0.1:8080.

## Publicación

GitHub Pages publica la raíz de la rama `main`. El archivo `.nojekyll` desactiva el procesamiento de Jekyll.

Este repositorio contiene únicamente la página informativa. No incluye el código de la aplicación, datos financieros ni credenciales.
